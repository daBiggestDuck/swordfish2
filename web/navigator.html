How to read this
Sun above the local horizon → panels can generate power (sine of elevation, slope-aware — approx, not array I–V curves). Earth above the local horizon → Direct-to-Earth radio is geometrically possible (not a full link budget / SNR). Horizons gives body direction; LOLA 36-bin horizons mask terrain. Labels stay honest when a site uses a flat-horizon fallback.
