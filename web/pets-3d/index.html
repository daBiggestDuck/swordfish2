Payload Pets · 3D

Instrument models

Catalog four: LISTER heat-flow drill, Retro corner-cube reflector, EDS dust shield, Nodey LN-1 beacon. Triddy (TRIDENT ice auger) stays available for moon-drop. Mount with renderPet3D(id, mood, el) or window.PayloadPets3D.

Drop sibling API

import { renderPet3D } from "/web/pets-3d/pets3d.js";

const handle = renderPet3D("lister", "day", mountEl);
handle.update("night");       // phases or moods
handle.setPet("LRA");         // aliases: lra, retro, LRA
handle.setSignal(90);         // Nodey antenna glow
handle.dispose();

Also: CANONICAL_PETS, resolvePetId, resolveMood from api.js (no WebGL). SVG moods remain in demos/js-pets.
